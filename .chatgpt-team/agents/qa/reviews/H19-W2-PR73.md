### Independent correctness/testability observations
- Five account and **seven distinct journal HTTP operations** match checked-in rc.4 paths and schema fields, including JournalPage, JournalDraftInput, DraftLine, Journal, JournalWarning, Idempotency-Key and reversal body. PATCH account fields only name/active, journal PUT entire draft. `voucher_number` optional/null before posting and server-assigned; `posted_at` nullable UTC; `reversal_of_id` nullable; status draft/posted and `reversed` boolean. Account full_code/postable are response-derived, never client-forged.
- Draft completeness warning vs true validation error is distinguished: missing draft fields can survive as warnings, malformed wire type or foreign-tenant account references cannot; saved unbalanced draft is **not posted**. UI does not assert local/BigInt/Decimal provisional total is a server-validated amount. Posting uses server response alone; posted journal cannot be edited; reversal creates a separate linked document. No assumption that Posting/Reverse is implemented.
- `Rial` canonical `^(0|[1-9][0-9]{0,19})$` ASCII string, no JS Number, no 21-digit truncation; Persian/Arabic keyboard digits can be normalized only at UI boundary with exact validation. `code` left zeros preserved; UUID/account/ISO have LTR isolation. Display Jalali dates converted to ISO Gregorian date-only API, fiscal half-open exclusive end, UTC timestamps and Asia/Tehran business cutoffs; no live timezone implementation asserted.
- Session/tenant change flushes stale company and selected accounts/fiscal drafts with warning, not client-side simulated authorization; every server mutation still requires H05 membership and Origin/CSRF. CSRF retry is human-triggered after one safe GET, unknown network outcome never blindly posts twice; idempotency key kept secret.
- H17 matches light/dark typography/tokens, Persian RTL, contrast/focus/reflow prescriptions. Design checklists specify cases for 360/390/600/1024/1280, 200% zoom, keyboard, screen-reader and reduced motion. **Actual UI contrast, a11y, responsive behavior are NOT_TESTED; descriptions do not prove they work.**
